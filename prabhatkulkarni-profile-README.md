## About

I am an Electronics and Communication Engineering undergraduate interested in building systems where **hardware, software, and intelligent computation meet**.

My current focus is on:

- Digital System Design and **Verilog RTL**
- FPGA development, simulation, and verification
- Embedded systems and sensor interfaces
- Machine learning and deep learning fundamentals
- **Edge AI** and efficient inference
- Signal processing and semiconductor technology

I prefer learning by **building, measuring, debugging, and documenting** rather than only studying theory.
